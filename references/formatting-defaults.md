# Formatting defaults

Standards: GB/T 7713.1—2025 for theses; GB/T 7713.2—2022 for academic papers; GB/T 7713.3—2014 for scientific/technical reports; GB/T 7714—2015 for references; GB/T 15834—2011 for punctuation. These standards do not impose every font, margin, or heading size below; supplied institutional rules override these defaults.

## Page
A4 portrait, single column. Margins: top 25 mm, bottom 25 mm, left 30 mm, right 25 mm, binding 0. Header/footer distance 15 mm. Use separate sections for cover, front matter, main matter, appendices, and landscape pages. Cover has no header or page number. Front matter uses uppercase Roman numerals; main text starts Arabic 1; later parts continue.

## Type and paragraphs
Body: Songti 12 pt Chinese, Times New Roman 12 pt Latin/digits, justified, first-line indent 2 Chinese characters, 1.5 line spacing, 0 pt before/after. Heading 1: Heiti 16 pt, left, 0/18 pt, page break before. Heading 2: Heiti 14 pt, 12/6 pt. Heading 3: Heiti 12 pt, 6/6 pt. Heading 4: Heiti 12 pt, 6/3 pt. Headings have no first-line indent and use native Heading 1–4 styles.

## Components
Use dedicated styles for abstract, keywords, TOC, captions, tables, equations, references, footnotes, code, and long quotations. TOC is a native field and normally includes Heading 1–3. Figure captions go below figures; table captions above tables. Default caption numbering is chapter-based. Tables fit the text area, repeat header rows, use 10.5 pt text, and do not have complex merged cells reconstructed automatically. Keep equations editable. References preserve the source citation system and use hanging indents. Footnotes stay as Word footnotes. Code/log whitespace is immutable.

Set Chinese and Latin fonts separately. Do not globally insert/remove spaces. Remove only layout-only repeated spaces and empty paragraphs in ordinary prose. Preserve special covers, floating graphics, SmartArt, OLE/MathType, complex tables, multi-column regions, protected content, and semantically meaningful fonts.
